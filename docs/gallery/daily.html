本周 AI 圈，
值得记住的 6 件事

导语：本周没有爆炸性发布，但有几条悄然发生的变化，会在三个月后被证明比发布会更重要。

✍️ 编者按：只挑真的值得记的，不凑数。每条都写清「为什么重要」，你可以只看蜜黄标记的那句话。

▎模型版

01 开源模型在长文本上首次反超闭源

某开源团队发布了 128K 上下文的模型，长文本评测跑赢同价位闭源产品。 意味着「私有化部署 + 长文档」第一次有了性价比方案。

02 两家大厂同步下调 API 价格

降幅 30%-50%，中小开发者的推理成本进一步走低。价格战打到这个位置，比拼的已经是工程效率而非融资能力。

▎工具版

03 浏览器 Agent 赛道挤进第三个玩家

主打「网页操作回放 + 一键复用」。实测对常见后台操作覆盖不错，复杂表单仍会翻车，建议先从固定流程用起。

04 终端 AI 工具开源

命令行里直接问「这报错什么意思」，中文文档场景友好。

05 笔记应用接入 Agent

自动把零散笔记整理成周报，隐私模式可选本地模型。

▎观点版

06 「提示词工程师」招聘量腰斩

招聘平台数据显示该岗位数量半年下降 52%。不是岗位消失，而是 提示词正在变成所有岗位的基础技能，而非独立职业。
